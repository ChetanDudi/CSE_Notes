-->Numpy: NumPy (short for Numerical Python) is the foundational open-source Python library used for scientific computing, data analysis, and machine learning. It adds support for large, multi-dimensional arrays and matrices, along with a massive collection of high-level mathematical functions to operate on them efficiently
        While Python lists are highly flexible because they can hold different data types, they are slow for processing massive datasets. 
        NumPy solves this by introducing the ndarray (N-dimensional array).
        NumPy arrays outperform standard Python lists due to several core mechanics:
                (i): Speed (C-Based Core): NumPy is written mostly in C. This allows calculations to run at compiled-code speeds rather than interpreted Python speeds.
                (ii): Contiguous Memory: Elements are stored right next to each other in memory. This allows your computer's processor to access and manipulate data drastically faster.
                (iii):Homogeneous Data: Every element in a NumPy array must be of the exact same data type (e.g., all integers or all floats). This eliminates data type checking overhead during loops.
                (iv): Vectorization: You can perform operations on an entire array at once without writing explicit for loops. For example, multiplying an entire array by 2 happens in one fast step.
                (v): Broadcasting: This feature allows mathematical operations to be performed between arrays of different shapes automatically.
        Use library import: import numpy as np , here np is an alias for numpy

-->Functions:
        1: Positional Arguments: Arguments are passed according to the position/order of parameters.
                def fun(name, age):
                        print(name, age)
                fun("Chetan", 23)
                Output:
                        → "Chetan" → name
                        → 23 → age

        2: Keyword Arguments: Arguments are passed using the parameter name, so order does not matter.
                fun(age=23, name="Chetan")

        3: *args: Used to accept any number of positional arguments. It stores them as a tuple.
                def fun(*args):
                        print(args)
                fun(10, 20, 30)
                Output: (10, 20, 30) as tuple

        4:**kwargs: Used to accept any number of keyword arguments. It stores them as a dictionary.
                def fun(**kwargs):
                        print(kwargs)
                fun(name="Chetan", age=23)
                Output: {'name': 'Chetan', 'age': 23} as dictionary

        5: Combined:
                def fun(a, *args, **kwargs):
                        print(a)
                        print(args)
                        print(kwargs)
                fun(10, 20, 30, name="Chetan", age=23)
        Output:
                → a → first positional argument
                → *args → remaining positional arguments → tuple
                → **kwargs → keyword arguments → dictionary

        Summary:
        → Positional → based on order
        → Keyword → based on name
        → *args → multiple positional → tuple
        → **kwargs → multiple keyword → dictionary
