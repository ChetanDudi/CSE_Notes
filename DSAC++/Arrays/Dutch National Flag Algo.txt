-->Dutch National Flag Algorithm: Used to sort an array containing only 0, 1, and 2 in one pass.

-->Maintain three pointers:
    low → position where next 0 should go
    mid → current element being examined
    high → position where next 2 should go
-->Logic:
    If arr[mid] == 0 → swap low and mid, then increment both.
    If arr[mid] == 1 → increment mid.
    If arr[mid] == 2 → swap mid and high, then decrement high. Do not increment mid because the swapped element still needs to be checked.

void sort012(vector<int>& arr) 
{
    int low = 0, mid = 0, high = arr.size() - 1;

    while (mid <= high) 
    {
        if (arr[mid] == 0) 
        {
            swap(arr[low], arr[mid]);
            low++;
            mid++;
        }
        else if (arr[mid] == 1) 
        {
            mid++;
        }
        else 
        {
            swap(arr[mid], arr[high]);
            high--;
        }
    }
}

-->Complexity:
    Time: O(n) — each element is processed a constant number of times.
    Space: O(1) — only three pointers are used.
    Passes: Single traversal.
    Stable: No. The relative order of equal elements is not guaranteed.

-->Key idea:
    [0s | 1s | unknown | 2s]
    low separates 0s, mid processes unknown elements, and high separates 2s.
