| **Type**                 | **Sort By**              | **Code Example (Full Formula)**                                                                                                                              |
| ------------------------ | ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `vector<int>`            | Ascending                | `sort(v.begin(), v.end());`                                                                                                                                  |
|                          | Descending               | `sort(v.begin(), v.end(), greater<int>());`                                                                                                                  |
| `vector<pair<int, int>>` | `.first` (default)       | `sort(v.begin(), v.end());`                                                                                                                                  |
|                          | `.second`                | `sort(v.begin(), v.end(), [](const pair<int, int>& a, const pair<int, int>& b) { return a.second < b.second; });`                                            |
|                          | `.second`, then `.first` | `sort(v.begin(), v.end(), [](const pair<int, int>& a, const pair<int, int>& b) { return a.second == b.second ? a.first < b.first : a.second < b.second; });` |
| `vector<vector<int>>`    | First column (default)   | `sort(v.begin(), v.end());`                                                                                                                                  |
|                          | Second column            | `sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) { return a[1] < b[1]; });`                                                          |
|                          | First, then second       | `sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) { return a[0] == b[0] ? a[1] < b[1] : a[0] < b[0]; });`                             |
|                          | Descending by second     | `sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) { return a[1] > b[1]; });`                                                          |
|                          | Third column (if exists) | `sort(v.begin(), v.end(), [](const vector<int>& a, const vector<int>& b) { return a[2] < b[2]; });`                                                          |
