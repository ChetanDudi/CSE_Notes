    -->JOINS:
        1:CROSS JOIN:Returns all combinations of rows from both tables (Cartesian product).
            EX:1:
                SELECT c.name, o.order_id
                FROM customers c
                CROSS JOIN orders o;
            EX:2:
                SELECT * FROM customers CROSS JOIN orders;
            If customers has 5 rows and orders has 5 rows → 25 rows in result.

        2:INNER JOIN:Returns only the rows that have matching values in both tables.
            Ex:1:
                SELECT c.name, o.order_id, o.order_date
                FROM customers c
                INNER JOIN orders o
                ON c.cus_id = o.cus_id;
            Only customers with orders will appear.

        3:LEFT JOIN (LEFT OUTER JOIN):Returns all rows from the left table, even if there’s no match in the right table.
        Missing right table values are shown as NULL.
        EX:1:
            SELECT c.name, o.order_id, o.order_date
            FROM customers c
            LEFT JOIN orders o
            ON c.cus_id = o.cus_id;
        Shows all customers, including those with no orders.

        4:RIGHT JOIN (RIGHT OUTER JOIN):Returns all rows from the right table, even if there’s no match in the left table
        Missing left table values are shown as NULL.
        EX:1:
            SELECT c.name, o.order_id, o.order_date
            FROM customers c
            RIGHT JOIN orders o
            ON c.cus_id = o.cus_id;
        Shows all orders, including those without corresponding customers.

        5:FULL OUTER JOIN (OUTER JOIN):Returns all rows when there’s a match in either left or right table.
        Missing values are shown as NULL.
        EX:1:
            SELECT c.name, o.order_id, o.order_date
            FROM customers c
            FULL JOIN orders o
            ON c.cus_id = o.cus_id;
        Shows all customers and all orders.
